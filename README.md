# NeonPlay 🎮

A neon-themed, responsive browser arcade website.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Choose a game and press **Play**.

No build tools, API keys, or dependencies are required for the static site.

## Publish free with GitHub Pages
1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Wait for GitHub Pages to publish the site. The URL will be shown in Settings → Pages.

## Project files
- `index.html` — website and browser game interface.
- `README.md` — project setup and publishing instructions.
- `.gitignore` — common local/editor files excluded from Git.

## Notes
This is a static website; it does not require a server-side backend. If you add assets or separate game files later, commit them to this repository too.
